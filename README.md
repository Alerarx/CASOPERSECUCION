### Publicación en GitHub Pages:
1. Ir a **Settings** -> **Pages**.
2. En **Build and deployment** / **Branch**, seleccionar main y / (root).
3. Hacer clic en **Save**. En 1 minuto la página estará en línea en https://<usuario>.github.io/<repositorio>/.
